Boarding algorithme

This project simulates passengers alighting and boarding a metro. In this picture below you can find the layout.

<img width="1142" height="638" alt="image" src="https://github.com/user-attachments/assets/ab3d3522-04be-4f5e-8bc8-2c8f6eac6777" />
Passengers will try to embark and disbark at the same time. They will have to navigate to get to their respected exits.
In this setting, everyone will follow the 'politeness rule'. This dictates that travelers who want to get off the train will get priority compared to the people who want to get up. 

This system is implemented by using blended and priority steering. This project took a lot of inspiration out of the flocking algorithme.
